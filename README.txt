IMD318 PROFESSIONAL PERSONAL WEBSITE
====================================

Open index.html to start.

Pages:
- Home
- Biodata
- Experience
- Education
- Family
- Gallery

Folders:
- css/style.css
- js/script.js
- images/profile.jpg

The website uses only HTML, CSS and JavaScript and is designed to be
edited with Notepad/Notepad++ and hosted with GitHub Pages.

Before submission:
1. Replace the repeated gallery images with your own photos.
2. Add your own video/audio files if required.
3. Check every navigation link.
4. Test the website locally.
5. Upload the complete folder to GitHub.
6. Enable GitHub Pages from the repository settings.
